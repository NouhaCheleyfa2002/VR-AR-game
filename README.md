An immersive Virtual Reality escape game built with React, WebXR, and Three.js, offering both single-player and multiplayer experiences. Players explore interactive 3D environments, solve puzzles, unlock levels, and collaborate with teammates to escape.

The project includes:

Frontend (React + WebXR + Three.js / A-Frame) – interactive VR/AR gameplay, puzzle solving, scene rendering.

Backend (Spring Boot / Node.js) – secure authentication with JWT, role-based access (admin & player), and RESTful APIs.

Admin Dashboard – manage escape games, scenarios, levels, puzzles, feedback, rooms, and players.

Gameplay Features – scoring system, hints with point deduction, QR-code room joining, real-time multiplayer readiness checks.

Data Management – feedback, partnerships, reports, and cultural elements linked to levels and scenarios.
